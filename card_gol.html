Card GOL (Game of Life)

Modo físico compartilhado sem iteração automática.

O que é Conway's Game of Life?

É um autômato celular onde células vivas e mortas evoluem usando regras simples.

Solidão
Menos de 2 vizinhos → morre
Sobrevivência
2 ou 3 vizinhos → continua viva
Superpopulação
Mais de 3 vizinhos → morre
Nascimento
Exatamente 3 vizinhos → nasce

Objetivo

Complete padrões escondidos na sua mão utilizando o grid compartilhado.

Quando alguém completar o quinto resgate, finalize a rodada atual. Quem tiver mais pontos vence.

Componentes

  • Baralho de padrões
  • Baralho de ações
  • 1 grid compartilhado 20×14
  • 1 dado

Grid Compartilhado

O grid utilizado é único para todos os jogadores.

Ele é formado por 4 grids menores 10×7 conectados.

Todos os jogadores modificam o MESMO espaço.

Preparação

  1. Monte o grid compartilhado vazio.
  2. Cada jogador compra 5 padrões.
  3. Cada jogador compra 4 cartas de ação.
  4. Escolha 2 para ficarem ativas.
  5. Mantenha 2 escondidas na mão.

Estrutura das Cartas de Ação

  • 2 ações ficam ativas
  • 2 permanecem escondidas na mão
  • Você SEMPRE deve terminar com 2 ações escondidas
Sempre que uma carta sair da sua mão:
  • por uso de Swap Grid
  • por uso de Clear Grid
  • por substituir uma ação ativa
Você deve imediatamente:
  1. descartar a carta usada, seja a ativa substituida, ou um Swap Grid/Clear Grid utilizado da mão
  2. mover uma carta escondida para slot ativo, se ocorreu substituição
  3. comprar nova carta de ação
  4. voltar a possuir 2 cartas escondidas
A nova carta pode vir:
  • do topo do baralho de ações
  • ou do descarte mais recente

Tipos de ação

  • Adicionar células vivas
  • Remover células vivas
  • Swap Grid (trocar posições)
  • Clear Grid (limpar completamente uma região)

Turno

Cada jogador possui 2 ações por turno

Para cada ação você pode:

  • Usar ação ativa
  • Trocar ação ativa
  • Usar Swap Grid
  • Usar Clear Grid

Troca de padrões

Troca de padrões não consome ações.

No início do turno você pode descartar 1 padrão.

Depois escolha UMA opção:

  • Comprar novo padrão do topo
  • Pegar o descarte mais recente

Dado

Ao adicionar ou remover células:

  1. Role o dado
  2. Resultado = quantidade máxima
  3. Você pode usar menos

Resgatando padrões

Você pode resgatar:
  • No início do seu turno
  • No final do turno de QUALQUER jogador
  • No fim de cada uma das suas ações
É permitido resgatar múltiplos padrões.

Ao resgatar:

  1. revele o padrão
  2. coloque na área pontuada
  3. compre novo padrão

Fim do jogo

Quando alguém fizer o quinto resgate:

  • termine a rodada atual
  • conte pontos
  • maior pontuação vence
Estas regras descrevem apenas o modo físico sem iteração automática. Um modo futuro utilizará app para evoluir grids automaticamente e validar padrões evoluídos.
